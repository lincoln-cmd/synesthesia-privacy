시네스티지아 개인정보 처리방침

시행일: 2026년 9월 22일 · 최종 수정일: 2026년 11월 4일

시네스티지아는 사용자의 개인정보를 중요하게 생각하며, 현재 버전에서는 계정 생성이나 개발자 서버를 통한 개인정보 수집을 하지 않습니다.

1. 기기 내에서 처리하는 데이터

학습 진행률, 문항별 정답 여부, 점수, 숙련도, 복습 일정, 사용자 지정 연습 세트와 학습 설정을 앱의 기기 내 저장소에 보관합니다. 이름, 이메일, 위치 정보는 앱에서 수집하지 않습니다.

2. 마이크 권한과 음성 처리

마이크는 시창, 프레이즈 모방, 입시 모의시험에서 사용자가 측정을 시작한 동안 음정과 타이밍을 분석하기 위해서만 사용됩니다. 음성은 기기 안에서 실시간으로 분석됩니다. 재청취가 필요한 훈련에서는 측정 음성이 앱 캐시에 임시 보관될 수 있으며 새 측정, 문항 이동 또는 화면 종료 시 삭제됩니다. 음성이나 녹음 파일은 개발자 서버 또는 제3자에게 전송되지 않습니다. 마이크 권한을 허용하지 않아도 이론, 청음, 보면, 리듬 등 나머지 기능을 사용할 수 있습니다.

3. 저장, 백업 및 보관 기간

학습 기록과 설정은 앱을 사용하는 동안 기기 내에 보관됩니다. 사용자가 Android 백업을 활성화한 경우 학습 데이터가 Google의 Android 백업 또는 기기 이전 기능에 포함될 수 있습니다. 캐시와 임시 데이터는 백업 대상에서 제외됩니다.

4. 외부 전송과 제3자 제공

현재 버전은 학습 데이터나 마이크 음성을 개발자 서버 또는 제3자에게 전송하거나 제공하지 않습니다. 광고 SDK와 외부 분석 SDK도 사용하지 않습니다.

5. 데이터 삭제

앱의 ‘설정 → 모든 학습 데이터 초기화’에서 점수, 숙련도, 레슨 진도, 연습 세트와 학습 설정을 삭제할 수 있습니다. Android 설정에서 앱 저장공간을 삭제하거나 앱을 제거해도 기기 내 데이터가 삭제됩니다. Android 백업에 저장된 복사본은 사용자의 Google 계정 백업 설정에 따라 관리됩니다.
